# Hiromap Static Website - V1

این نسخه اولیه سایت استاتیک فارسی Hiromap است.

## فایل‌ها
- `index.html` صفحه اصلی
- `products.html` صفحه محصولات
- `style.css` استایل RTL فارسی
- `script.js` منوی موبایل
- `robots.txt`
- `sitemap.xml`

## روش استفاده در GitHub Pages
1. یک repository جدید بسازید.
2. همه فایل‌ها را آپلود کنید.
3. از مسیر Settings → Pages، Branch را روی `main` و Folder را روی `/root` قرار دهید.
4. بعد از تست، می‌توان دامنه را به GitHub Pages وصل کرد.

## نکته مهم SEO
قبل از جایگزینی WordPress، باید URLهای فعلی دقیق بررسی شوند. اگر آدرس‌ها عوض شوند، باید 301 redirect تعریف شود.
